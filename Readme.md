# 漢字 · Каллиграфический тренажёр

Веб-приложение для изучения китайской каллиграфии. Работает на iPhone, Android и десктопе.

## 📱 Установка на iPhone / iPad

1. Откройте сайт в **Safari** (только Safari!)
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх) внизу экрана
3. Прокрутите вниз и выберите **«На экран "Домой"»**
4. Нажмите **«Добавить»** в правом верхнем углу
5. Иконка 漢 появится на рабочем столе — приложение готово!

> 💡 Приложение откроется в полноэкранном режиме, без адресной строки Safari.

## 📱 Установка на Android

1. Откройте сайт в **Chrome**
2. Chrome автоматически предложит **«Добавить на главный экран»** (появится баннер внизу)
3. Или нажмите **⋮** (меню) → **«Установить приложение»** / **«Добавить на главный экран»**
4. Подтвердите установку

> 💡 После установки приложение работает даже без интернета!

## 🌐 Развёртывание (обязательно HTTPS!)

PWA требует HTTPS. Бесплатные варианты:

### GitHub Pages (проще всего)
1. Создайте репозиторий на GitHub
2. Загрузите все файлы
3. Settings → Pages → Source: `main` branch → Save
4. Через 1-2 минуты сайт будет на `https://ваш-логин.github.io/имя-репо/`

### Netlify (быстро)
1. Зайдите на [netlify.com](https://netlify.com)
2. Перетащите папку с файлами в окно
3. Получите HTTPS-ссылку вида `https://random-name.netlify.app`

### Vercel
1. Зайдите на [vercel.com](https://vercel.com)
2. Импортируйте проект с GitHub
3. Деплой автоматический
